# Examples & Code Samples (`examples/`)

## Purpose
The `examples` directory provides sample code, usage walkthroughs, plugin implementations, and integration blueprints demonstrating how to use and extend **NeuroFlow AI**.

## Responsibility
- Host functional code examples demonstrating AI agent execution, RAG pipelines, and plugin SDK integrations.
- Offer starter templates for custom domain plugin developers.
- Provide clear reference code for community contributors.

## What Belongs Here
- Example Python scripts demonstrating backend SDK usage.
- Sample plugin implementation templates.
- End-to-end integration walkthroughs.

## What Does NOT Belong Here
- Production backend source code.
- Live secrets, private API keys, or production configuration parameters.

- Add Telecom Intelligence plugin example walkthrough script.
- Add custom RAG ingestion pipeline usage example.
