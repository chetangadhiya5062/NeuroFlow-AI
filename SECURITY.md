# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability

The NeuroFlow AI maintainers take security seriously. If you discover a security vulnerability within NeuroFlow AI, please follow these reporting procedures:

1. **Do not create a public GitHub issue.**
2. Send a detailed report describing the vulnerability, affected components, and potential impact to the project maintainers.
3. Include steps to reproduce or a proof of concept if available.

### Response & Handling Timeline
- **Acknowledgement**: Within 48 hours of report submission.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Disclosure**: Coordinated release schedule following fix verification.
